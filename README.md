## 🎯 Sobre mim

Fala! 👋 Sou o Éder, estudante de **Análise e Desenvolvimento de Sistemas (ADS)** e absolutamente viciado em transformar dados bagunçados em informação que faz sentido pra alguém tomar uma decisão melhor. 🔥

Comecei no desenvolvimento web, mas foi ao mexer com dados de verdade que percebi: **é aqui que eu quero construir minha carreira**. Hoje meu foco total é **Dados, SQL, Python e Cloud Computing** — e eu tô nessa estrada todos os dias, sem pular etapa. 🚂💨

O que me move agora:

- 📊 Montar pipelines de **ETL** e domar dados soltos com **Python + Pandas**
- 🗄️ Modelar bancos relacionais e escrever **SQL** que realmente responde perguntas de negócio
- ☁️ Colocar a mão na massa em **Google Cloud Platform (GCP)** — e AWS já entrando no radar 👀
- 📈 Evoluir sem parar rumo a **Power BI** e **Engenharia de Dados**

> 💡 Minha marca registrada é disciplina + prática. Eu aprendo fazendo, erro, ajusto, documento e sigo pro próximo projeto. Cada repositório aqui é uma prova disso.

## 🗄️ SQL & Banco de Dados — onde eu me sinto em casa

Modelar banco e escrever query boa é o que mais me deixa animado no dia a dia. Já apliquei na prática:

- ✅ Modelagem relacional e **DER** (Diagrama Entidade-Relacionamento)
- ✅ Definição de **chaves primárias e estrangeiras**
- ✅ Relacionamentos **1:N** e **N:N**
- ✅ **JOINs** (INNER, LEFT, RIGHT) para consultas entre múltiplas tabelas
- ✅ **GROUP BY** e **funções agregadoras** (SUM, COUNT, AVG) para relatórios
- ✅ Extração, tratamento e carga de dados (**ETL**) integrando Python e MySQL
- ✅ Boas práticas de normalização e organização de esquemas relacionais

## 🚀 Projetos em destaque — bora ver na prática!

### 📦 1. Pipeline ETL de Vendas — Python + MySQL
Pipeline de **ETL (Extração, Transformação e Carga)** desenvolvido em Python, aplicando tratamento e limpeza de dados com Pandas e carregando o resultado em um banco de dados relacional MySQL — simulando um fluxo real de dados de vendas para análise posterior.

**Conceitos aplicados:** ETL · Tratamento de Dados · Data Cleaning · Pandas · SQL · Banco Relacional
🔗 [Ver repositório](https://github.com/ederfelixsilva/elt-vendas-python-mysql)

---

### 📊 2. Análise de Vendas E-commerce
Projeto de **análise de dados de vendas de e-commerce**, com exploração, tratamento e interpretação de dados para geração de insights de negócio — aplicando o ciclo completo de análise exploratória sobre uma base comercial.

**Conceitos aplicados:** Análise Exploratória de Dados · Python · Pandas · Interpretação de Dados para Negócio
🔗 [Ver repositório](https://github.com/ederfelixsilva/analise-vendas-ecommerce)

---

### 🧾 3. Sistema de Ordem de Serviço — Banco de Dados MySQL
Banco de dados relacional projetado para o controle de ordens de serviço de uma assistência técnica, contemplando modelagem completa, definição de relacionamentos e consultas voltadas à geração de relatórios operacionais.

**Conceitos aplicados:** Modelagem Relacional · DER · Chaves Primárias/Estrangeiras · Relacionamentos 1:N e N:N · JOINs · GROUP BY · Funções Agregadoras
🔗 *Repositório: atualize o link aqui (ex: `github.com/ederfelixsilva/sistema-os-mysql`)*

### ☁️ 4. GCP HTTP Load Balancing
Projeto de infraestrutura em nuvem utilizando **Google Cloud Platform**, com provisionamento de máquinas virtuais via Compute Engine e configuração de um **Load Balancer HTTP** para distribuição de tráfego — primeiro contato prático com Cloud Computing.

**Conceitos aplicados:** Compute Engine · Máquinas Virtuais · Load Balancer · Cloud Computing
🔗 [Ver repositório](https://github.com/ederfelixsilva/gcp-http-load-balancing)
